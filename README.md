## Compact Jr – Landing Page

Este repositório contém o desenvolvimento de uma landing page institucional criada como parte do processo trainee da Compact Jr.

## Sobre o projeto

A proposta consistia na criação de uma landing page completa para representar uma empresa, com foco em organização, clareza visual e boas práticas de desenvolvimento web.

Este projeto representa a etapa final do processo trainee, consolidando as etapas anteriores em um produto funcional.

## Etapas do processo trainee

O desenvolvimento foi dividido em três fases principais:

### Backlog
Levantamento e organização dos requisitos do projeto, definindo funcionalidades e estrutura da aplicação.
### Protótipo
Criação do design da interface, priorizando usabilidade, estética e experiência do usuário.
### Desenvolvimento (este repositório)
Implementação da landing page com base no planejamento e protótipo definidos anteriormente.

## Funcionalidades da landing page

A página foi estruturada com as seguintes seções:

História – apresentação da empresa e seu contexto

Serviços – descrição dos serviços oferecidos

Contatos – área dedicada para comunicação com a empresa

## Tecnologias utilizadas
HTML5

CSS3

JavaScript

## Deploy

A aplicação foi publicada utilizando o GitHub Pages, permitindo acesso direto via navegador sem necessidade de backend.
